一款快速的 Markdown 文档查看器和编辑器。只有在你按 Ctrl+S 保存时才会修改文件。

打开文档

  • 在文件资源管理器中双击任意 .md 文件。
  • 将文件拖到窗口上。
  • 按 Ctrl+O，或使用工具栏上的文件夹按钮。

文档在工具栏的标签页中打开。应用运行时从外部打开的文件（双击、打开方式、leggimi 文件.md）会在你最后使用的窗口中新开一个标签页；如果该文件已经打开，它的标签页会切换到前台。在应用内，单击文件、最近文档、搜索结果或链接会在当前标签页中打开它；Ctrl+单击（或按鼠标中键）会在后台的新标签页中打开，Ctrl+Shift+单击在前台的新标签页中打开，Shift+单击则在新窗口中打开，右键菜单中的在新标签页中打开和在新窗口中打开也一样。用 Ctrl+O 打开或拖到窗口上的文件各占一个标签页。同一个文档在同一窗口中不会打开两次：再次打开时会把它的标签页切换到前台。

新标签页显示起始页，其中列出最近打开的文件：单击即可在该标签页中打开。每个文档还会记住你上次读到的位置，再次打开时自动回到那里。

不是 UTF-8 编码的文件也能打开：UTF-16（Windows PowerShell 5.1 用 > 或 Out-File 写出的就是这种），以及 Windows 的 ANSI 代码页（Set-Content 和较老的程序使用它，例如简体中文 Windows 上的 GBK）；文件夹搜索也能读取它们。Leggimi 始终以 UTF-8 保存，并在第一次保存这类文件时告诉你。

粘贴即读：从聊天（ChatGPT、Claude）、网页、Word 或 Teams 复制的文本无需先保存即可作为 Markdown 阅读。在编辑器和文本框（查找栏、筛选框）之外的任意位置按 Ctrl+V，或使用起始页上的从剪贴板粘贴或命令面板中的将 Markdown 粘贴为新文档，文本就会在单独的标签页中打开，并以其第一个标题（没有标题时为第一行）命名：如果前台是起始页，起始页就变成该文档，否则在前台新开一个标签页。它像任何文档一样可以使用大纲、查找、打印、PDF、Word 和复制；Ctrl+E 编辑，Ctrl+S 将其保存为文件（另存为…，按标题建议文件名），此后它就是普通文档。未修改时关闭其标签页不会询问，窗口关闭前可用 Ctrl+Shift+T 重新打开；有修改时，Leggimi 会询问是否保存。关闭窗口时则无论是否修改都会询问：这段文本不在任何文件中，会随窗口一起消失。指向其他文件的链接和图片要在保存到文件夹后才能使用（在此之前，指向其他文件的链接会给出提示）。如果 Leggimi 在有修改时意外关闭，下次启动时文本会连同修改一起回来。只能粘贴文本（剪贴板中是图片时会有提示）；在编辑器中，Ctrl+V 照常粘贴。

用聊天的复制按钮复制的 Markdown 会原样读取。用鼠标选中的部分回答，或网页、Word、Teams 中的一段内容，会保留标题、列表、表格、代码块、链接和公式：Leggimi 会读取与文本一起放到剪贴板上的带格式副本，并将其转换为 Markdown。从终端（Claude Code、psql、MySQL）复制的、用框线字符绘制的表格会变成 Markdown 表格，用制表符分隔单元格的多行文本（仅以文本复制的表格，或从 Excel 复制的内容）也会如此；整个包在 ```markdown 代码块中的回答，会按其中的文档来阅读；写成 \( … \) 或 \[ … \] 的公式（ChatGPT 的写法）会作为公式显示。文本被转换为 Markdown 时会有提示，点击按原样显示即可看到复制时的原样内容。

在终端中，leggimi 文件.md 打开文件，--line 40 则定位到该行，--new-window 在单独的窗口中打开（不带文件的 leggimi --new-window 会打开一个空窗口）；安装后即可使用 leggimi 命令。

标签页和窗口

按 Ctrl+T 或单击最后一个标签页后面的 + 可打开新标签页，按 Ctrl+Shift+N 可打开新窗口。Ctrl+W 关闭标签页，单击标签页上的 × 或用鼠标中键单击它也一样：关闭最后一个文档后会留下起始页，只剩起始页时按 Ctrl+W 会关闭窗口。Ctrl+Shift+W 关闭窗口及其所有标签页，Ctrl+Shift+T 重新打开最近关闭的标签页。关闭有未保存更改的标签页前会先询问：保存、不保存或取消；关闭窗口时只询问一次，并列出有未保存更改的文档和尚未保存为文件的粘贴文本。

Ctrl+Tab、Ctrl+1 … 9 以及键盘快捷键中的其他标签页按键可用键盘在标签页之间切换。每个标签页都保留自己的阅读位置、编辑内容和撤销记录、后退 / 前进历史记录以及文件面板的文件夹。将鼠标指针停在标签页上可查看其所在文件夹和阅读时间；标签页放不下时，标签栏末尾的箭头会列出全部标签页。右键单击标签页可选择移至新窗口、关闭其他标签页、关闭右侧标签页、复制路径和在文件资源管理器中显示。

沿标签栏拖动标签页可调整顺序（按 Esc 可放回原处）。把它拖出标签栏，它会在自己的新窗口中打开，窗口随指针移动；把它放到另一个 Leggimi 窗口的标签栏上，它就会移到那里，未保存的更改和撤销记录也一并带上。拖动窗口中唯一的标签页会移动整个窗口，把它放到另一个窗口的标签栏上会将两个窗口合并。

工具栏同时也是窗口的标题栏，颜色跟随主题：拖动其空白处可移动窗口，双击可最大化或还原窗口，将鼠标指针停在“最大化”按钮上可使用 Windows 11 的贴靠布局。

文档顶部的细线显示阅读进度；当前标签页会在名称后显示预计阅读时间（标签栏已满时，将鼠标指针停在该标签页上即可查看）。

在选中的文字上按 Ctrl+C，会连同格式一起复制（可直接粘贴到 Word 或 Outlook），同时也复制纯文本。文档还可以像纸张一样拖动：在任何位置按住鼠标中键，或在文字旁边的空白处按住左键。

在文档上右键（或按 Shift+F10 或菜单键）可打开其菜单：复制所选内容（带格式或纯文本），或在文档、文件夹中搜索它；打开或复制链接；用打开预览打开图片、图表或表格，复制代码块或表格；复制指向此章节的链接会得到 [标题](文件.md#标题)，这个链接在任何其他文档中都能使用，在 GitHub 上也一样；从此处编辑会在该处打开编辑器；复制整个文档连同格式复制整篇文档，与 Ctrl+Shift+C 相同；打印或保存为 PDF。

和浏览器一样，Alt+←（或鼠标侧面的后退键）会回到你点击章节链接、点击大纲或切换到另一个文档之前的位置；Alt+→（或前进键）再前进。右键菜单顶部也有后退和前进。每个标签页都有自己的历史记录。

在命令面板中输入几个字母，即可找到命令（旁边显示其快捷键）、文档中的标题、已打开的标签页、文件夹中的文件或最近的文件；不区分重音符号和大小写，命令的英文名称在任何语言下都可使用。Enter 执行或打开；Ctrl+Enter 在新标签页中打开文件，Ctrl+Shift+Enter 在前台的新标签页中打开，Shift+Enter 在新窗口中打开；以 > 开头只显示命令，以 # 开头只显示文档的标题；Esc 关闭。没有专用按键的命令也在其中（保存为 PDF、导出为 HTML / DOCX、保持置顶、各个主题、每个一级标题另起一页、阅读设置），编辑时还有编辑器的命令。在编辑器中 Ctrl+K 用于插入链接，因此要用 Ctrl+Shift+P 打开命令面板；Ctrl+P 仍用于打印。

编辑

按 Ctrl+E 或铅笔按钮（编辑）编辑当前文档：左侧是文本编辑器，右侧是实时预览。编辑时，该按钮显示为一本打开的书：返回阅读。窗口宽度小于约 760 像素时只显示编辑器；窗口变宽或返回阅读时，预览会重新出现。

文档标签页上取代 × 的橙色圆点表示有未保存的更改，按 Ctrl+S 保存后，圆点会短暂变成一个对勾（屏幕阅读器会读出“已保存”）。在有未保存更改时退出编辑模式，或在同一标签页中打开其他文档，会像关闭标签页时一样先询问：保存、不保存或取消；“保存”排在第一位，因此按 Enter 不会丢失你的工作。如果文件在你有未保存更改时在磁盘上发生变化，会显示提示而不是覆盖你的工作；覆盖保存一个在打开后已被修改的文件时，也会先询问。提示中的从磁盘重新加载会把磁盘上的文本放入编辑器，而且可以撤回：使用随后提示中的撤销，或在编辑器中按 Ctrl+Z，你的更改就会回来（仍未保存）。

编辑时，在预览中双击某个词，编辑器的光标就会移到这个词上，预览保持不动；阅读时，双击照常选中一个词。

格式：编辑器上方的格式栏可对选中内容（或光标所在的词）设置格式，并插入表格、Mermaid 图表、公式和提示框。在行首输入 / 可按名称选择块。在选中的文字上粘贴链接会将其变成 Markdown 链接。

工具（格式栏右侧的滑块按钮）汇集了查找与替换、行命令、注释当前行和拼写检查。注释当前行（Ctrl+/，即 Ctrl 加上能输入 / 的按键；在意大利语或德语键盘上为 Ctrl+Shift+7）用 <!-- --> 包裹这些行，阅读时它们会被隐藏；在代码块中则使用该语言的注释，再执行一次即可取消。拼写检查会用界面语言的词典给拼错的单词加下划线，右键可查看更正建议（在阅读设置中更改语言后，下次启动时生效）。

Tab 用于缩进。要用键盘离开编辑器，先按 Esc，再在两秒内按 Tab；如果有选中的文字，或打开了面板（如查找与替换）或菜单，请先按两次 Esc。

恢复：只要有未保存的更改，文本副本就会被保留在一旁。如果应用未保存就关闭了（崩溃、强制关机），下次打开该文件时会有提示询问是否恢复。在你保存之前，文件本身绝不会被改动；保存时要么写入整个文件，要么什么也不写：文本先写入文档旁的临时文件，再由它取代原文件，因此保存中途断电或驱动器断开，也绝不会留下空白或残缺的文件。

图片：粘贴截图（Ctrl+V）或把图片文件拖进编辑器，它会保存到文档旁的 assets 文件夹，并以相对路径链接。

浏览文件

左侧面板列出你打开的文件夹中的 Markdown 文件，最多四层子文件夹。从面板打开文件会保持同一个根文件夹，不会迷失方向；用文件旁的向上箭头把根移到上级文件夹。打开当前文件夹之外的文档会把面板移到那里。你折叠的文件夹在浏览期间保持折叠，重启后也是如此。

没有 Markdown 文件的文件夹会被隐藏，隐藏文件夹和 node_modules 之类的构建文件夹也一样。

文件夹中添加、重命名或删除文件时，面板会自动更新。重命名当前打开的文档时，窗口会跟着它；删除或移走它时，文字仍留在屏幕上，并有提示提供重新保存。

使用键盘时，列表像树一样操作：↑ / ↓ 移动，→ 展开文件夹或进入其中，← 折叠文件夹或回到上级，Home / End 跳到首尾，Enter 或 空格 打开，Ctrl+Enter 在新标签页中打开。

两个侧边面板都可以拖动内边缘加宽，双击边缘恢复默认宽度。它们的文字大小跟随阅读设置中的面板。

窗口最窄可以缩到 480 像素：笔记本屏幕的一半，或 Windows 11 的贴靠布局。窗口变窄时，大纲和文件列表会先后自动收起；这时点击它们在工具栏上的按钮（或按 Ctrl+I 和 Ctrl+B）会让它们浮在文字上方打开，按 Esc、点击其他地方或选择一项后即会收起。

目录树上方的搜索框（Ctrl+Shift+F）在文件夹的每个 Markdown 文件中查找文本，结果显示文件和片段，打开结果会在文档中高亮该词。Esc 清除搜索并恢复目录树。

大纲

右侧面板列出文档的标题，并高亮你正在阅读的那个。单击任意条目即可跳转。长文档的列表上方会出现筛选框：输入以缩小标题范围（没有符合的标题时显示没有匹配项），然后用 ↑ / ↓ 和 Enter 跳转；Esc 清空筛选。

跳转之后（通过大纲、章节链接、. / , 键或 --line），你到达的标题或段落会短暂高亮，方便目光找到它。后退和前进不会触发高亮。

大纲关闭或窗口太窄无法显示大纲时，文字顶部的一条细栏会显示你正在阅读的章节：该章节的标题及其所属的上级标题，例如 2. 决策 › 2.1 预算，不含文档标题。该章节标题滚出视野后它才会出现；当顶部是标题或表格的表头行时，它会让开。单击其中某一部分可回到该标题。它只在阅读时显示（编辑器的预览中没有），也不会被打印。

自动刷新

打开的文件都会被监视。文件变化时，视图自动刷新并保持阅读位置，即使你正在阅读的章节标题改变了也一样（例如 AI 智能体把某一步标记为完成）——在文档被重新生成时很有用。已经绘制的 Mermaid 图表会立即以原有高度重新出现，因此文字不会移动。后台的标签页会在你切换回去时更新。编辑模式下，只有缓冲区没有未保存更改时才会刷新；否则会有提示提供从磁盘重新加载（见编辑）。

按 F5 或 Ctrl+R 可随时重新读取文件并保持阅读位置；有未保存的更改时不执行任何操作。

渲染

  • GitHub 风格的 Markdown：表格、任务列表、删除线、自动链接。网址会变成链接，以 www. 开头的也一样，与 GitHub 相同；README.md 之类的文件名仍是普通文本。
  • 换行遵循 CommonMark，与 GitHub 显示文件时相同：段落内的单个换行视为一个空格；要换行，请在行尾加两个空格或一个反斜杠（\）。
  • 代码块带语法高亮，悬停时有复制按钮。
  • mermaid 代码块渲染为图表；语法无效时回退为代码块并附错误说明。
  • 比阅读栏更宽的表格或图表会居中展开，最宽可占满全部可用宽度：无需横向滚动，图表的文字也保持原有大小。
  • 阅读长表格时，表头行会停留在窗口顶部，直到表格的最后一行滚过。即使占满整个窗口仍然过宽的表格可以横向滚动：只要表格还在视野中，它的滚动条就会停留在窗口底部，无需滚到表格末尾才能左右移动；在表格任意位置也可以使用 Shift+滚轮或触摸板。
  • 单击图表或图片可全窗口打开：+ / − 或滚轮缩放，拖动平移，Esc 关闭。适应（0）使其适应窗口，宽度（W）使其适应宽度并从顶部开始，100%（1）按实际大小显示。复制按钮可提供 PNG 图片（普通或大图），图表还可提供 SVG，两者都可以保存为文件。
  • 公式使用 KaTeX 渲染：行内 $…$，独立公式用 $$…$$ 或 math 代码块（math 后带标题也可以）。美元符号的解析与 GitHub 相同：$$ 块只有在闭合时才会开始，因此 $$ 100 这样的价格不会把文档其余部分变成公式；闭合的 $$ 之后的文字会保留；句中的 $$…$$ 会显示公式而不拆分段落；内侧带空格的 $ x $ 以及 $5 和 $10 这样的金额仍是普通文本。
  • 提示框：以 [!NOTE]、[!TIP]、[!IMPORTANT]、[!WARNING] 或 [!CAUTION] 开头的引用（与 GitHub 相同），或以 Obsidian 等笔记应用所写笔记中的其他类型开头的引用（[!info]、[!todo]、[!example]、[!danger]…），按 GitHub 五种提示框中最接近的一种着色。类型后面的标题（> [!tip] 开始之前）会取代类型名称；写成折叠形式的提示框（[!note]-）会以展开状态显示。
  • ==高亮文字== 会被高亮显示，在所有主题、打印和 Word 中都是如此。
  • 脚注：正文中的 [^1] 和任意位置的 [^1]: …；脚注汇集在文末，带有来回跳转链接。
  • 任务列表是可交互的：单击复选框会立即更新文件中的 [ ] / [x]（提示中有撤销），编辑时则更新编辑器缓冲区。只有复选框才能勾选任务：单击或双击任务文字（例如为了选中一个词）不会改变任何内容。
  • 表格右上角有两个按钮，鼠标悬停或用键盘到达时显示：复制表格（用于 Excel）把表格以制表符分隔的文本放入剪贴板，可直接粘贴到 Excel 或 Google 表格；打开预览以全窗口打开表格，便于阅读（右键菜单中也有）：它像页面一样滚动，标题行停留在顶部；表格横向滚动时，第一列也停留在左侧；+ / − 或 Ctrl+滚轮调整文字大小，宽度（W）使表格适应窗口。筛选行（Ctrl+F）只保留包含所输入词语的行；单击列标题即按该列排序：升序、降序、恢复原始顺序（能识别数字、金额、百分比和日期）。文档不会改变，预览中的复制表格（用于 Excel）按你看到的样子复制行。
  • 指向其他文档的链接像 wiki 一样工作：[文字](other) 找到 other.md，[文字](folder/) 打开该文件夹的 index.md 或 README.md，other.md#section 跳转到该标题。标题的锚点与 GitHub 相同（## 1. 简介 → #1-简介），因此为 GitHub 编写或由 AI 助手生成的目录在这里同样可用；为早期版本写的链接也仍然有效。
  • 用 Obsidian 等笔记应用所写笔记中的链接也能使用：[[笔记]]、[[笔记|其他名称]] 和 [[笔记#标题]] 会打开 笔记.md，先在文档旁查找，再按名称在文件面板的文件夹中查找。![[图片.png]] 显示图片，![[图片.png|300]] 以 300 像素宽显示；图片在文档所在文件夹及其子文件夹中查找，因此位于同级文件夹中的图片找不到。
  • --- 行之间的 YAML front matter 会折叠成顶部的 Front matter 区块：单击可以表格形式查看字段。
  • 只包含 [TOC] 的段落会变成后续标题的目录，打印、HTML 和 DOCX 中也会保留。
  • 相对路径的图片相对于文档所在文件夹解析。为 GitHub 浅色和深色主题制作的徽标（标有 #gh-dark-mode-only / #gh-light-mode-only，或带有浅色和深色来源的 <picture>）会显示与 Leggimi 当前主题相符的那一个；打印和导出使用浅色版本。
  • 网页链接在默认浏览器中打开，mailto: 链接在邮件应用中打开；指向其他 Markdown 文件的链接在查看器中打开，指向图片的链接在预览中打开，指向文件夹的链接在文件面板中打开。指向其他文件（PDF、电子表格）的链接会提示用其对应的应用打开。
  • 文本中的简单 HTML 可以使用：<br>、<kbd>、<sup>、<details>、图片（包括 <picture> 和 srcset），以及文档所在文件夹中的视频和音频。和 GitHub 一样，不是 HTML 的标签（如 <name>）不会显示：要显示它，请用反引号括起来（`<name>`）或在前面加反斜杠（\<name>）。会改变页面的标签，如 <style>、<script>、<title> 和 <iframe>，会显示为文本。

分享与导出

分享按钮（Ctrl+Shift+E）汇集了所有从应用输出的方式：

  • 复制为富文本（Ctrl+Shift+C）：把渲染后的文档连同格式放入剪贴板，可直接粘贴到 Outlook、Word 或 Teams。本地图片会被嵌入。
  • 打印…（Ctrl+P）：只打印文档，按纸张排版，始终使用浅色背景，每页顶部有标题和日期，底部有“页码 / 总页数”；比页面宽的表格会缩小以适应页面。
  • 保存为 PDF：同样的排版直接写入 PDF 文件，除了选择文件外没有其他对话框。菜单中的每个一级标题另起一页选项会被记住，对两者都有效。
  • 导出为 HTML / DOCX：把文档保存为可在任何浏览器中打开的单个独立 .html 页面，或为 Microsoft Word 优化的 .docx——公式变成 Word 原生公式，图表变成图片。

无论当前的阅读设置如何，打印和导出始终使用标准的文字排版。

阅读设置

Aa 按钮打开阅读设置：文字大小、无衬线或衬线字体、行距、栏宽、界面语言和主题：浅色、棕褐（暖纸色）、深色、纯黑（适合 OLED 屏幕）或自动（跟随 Windows 的浅色或深色）。文字大小在任何地方都可以用 Ctrl+= / Ctrl+−、Ctrl+滚轮调整，Ctrl+0 重置；编辑器文字也会随之缩放。面板单独设置文件列表和大纲的文字大小——在面板上用 Ctrl+滚轮只改变该面板。所有选择在重启后都会保留。

如果关闭了 Windows 的动画效果（设置 > 辅助功能 > 视觉效果），滚动会直接跳转而不是平滑滑动，跳转后的高亮也不会有动画。

Windows 集成

你打开的文件会加入 Windows 的“最近使用的项目”和任务栏上应用的跳转列表。安装程序注册关联后，在文件资源管理器中双击任意 .md 文件即可在此打开。

在文件资源管理器中，新建 → Markdown 文档（在文件夹中右键）会创建一个空的 .md 文件。使用安装程序时，这个名称以及资源管理器类型列中的文件类型名称都跟随 Windows 的显示语言；Microsoft Store 版本中该项始终名为 Markdown document。

在面板中的文件上右键，可选择在新标签页中打开、在新窗口中打开、在文件资源管理器中显示、复制路径或复制为 Markdown 链接（相对于当前文档）。图钉按钮让窗口保持在其他窗口之上；它不再有快捷键，因为 Ctrl+Shift+T 现在用于重新打开最近关闭的标签页。
