A fast viewer and editor for Markdown documents. Files are only modified when you save with Ctrl+S.

Opening documents

  • Double-click any .md file in File Explorer.
  • Drag a file onto the window.
  • Press Ctrl+O or use the folder button in the toolbar.

A file opened from outside while the app is running (a double-click, Open with, leggimi file.md) gets a window of its own; if it is already open, its window comes to the front. Inside the app, files open in the same window: Ctrl+click (or the middle button) on a file, a recent document, a search result or a link opens it in a new window instead, as does Open in a new window in its right-click menu, and Ctrl+Shift+N opens an empty one. Several files opened together (Ctrl+O or dragged) go one per window.

With no document open, the window lists the files you opened recently: click one to reopen it. Every document also remembers where you stopped reading and scrolls back there when you open it again.

From a terminal, leggimi file.md opens a file and --line 40 opens it at that line (the leggimi command is available once the app is installed).

A thin bar along the top of the document shows how far you are, and the toolbar shows the estimated reading time.

Ctrl+C on a selection copies it with its formatting, ready for Word or Outlook, as well as plain text. The document can also be dragged like a sheet of paper: with the middle mouse button anywhere, or with the left button on the empty space beside the text.

Right-click the document for its menu: copy the selection (with its formatting or as plain text) or search for it in the document or the folder; open or copy a link; open an image or a diagram, copy a code block or a table; copy a link to the section, [Heading](file.md#heading), which works from any other document; edit from that point; print or save as PDF.

Like in a browser, Alt+← (or the mouse's side back button) returns to where you were before a link to a section, a click in the outline or a move to another document; Alt+→ (or the forward button) goes forward again. Back and Forward are also at the top of the right-click menu. Each window has its own history.

Editing

Press Ctrl+E or the pencil button to edit the open document: the text editor appears on the left, with a live preview on the right. An orange dot next to the file name marks unsaved changes — save with Ctrl+S. Leaving edit mode or opening another document with unsaved changes asks for confirmation first. If the file changes on disk while you have unsaved edits, a warning appears instead of overwriting your work, and saving over a file that changed since you opened it asks before overwriting it.

Formatting: the bar above the editor formats the selection — or the word under the cursor — and inserts tables, Mermaid diagrams, formulas and callouts. Type / at the start of a line to pick a block by name. Pasting a link over selected text turns it into a Markdown link.

Tools (the sliders button at the right of the bar) collects find & replace, the line commands and Spellcheck, which underlines misspelled words with the dictionary of the interface language, with suggestions on a right-click (after a language change in the reading settings, from the next start).

Recovery: while you have unsaved changes, a copy of the text is kept aside. If the app is closed without saving (a crash, a forced shutdown), the next time you open that file a notice offers to restore it. The file itself is never touched until you save.

Images: paste a screenshot (Ctrl+V) or drop an image file into the editor — it is saved to an assets folder next to the document and linked with a relative path.

Browsing files

The left panel lists the Markdown files in the folder you opened, up to four levels of subfolders. Opening a file from the panel keeps the same root folder, so you never lose your place; use the up arrow next to Files to move the root to the parent folder. Opening a document from outside the current folder re-roots the panel there. Folders you collapse stay collapsed while you navigate — and across restarts.

Folders without Markdown files are hidden, as are hidden and build folders such as node_modules.

The pane updates by itself when files are added, renamed or deleted in the folder. Rename the open document and the window follows it; delete or move it and its text stays on screen, with a notice offering to save it again.

Both side panels can be widened by dragging their inner edge — double-click the edge to restore the default width. Their text size follows Panels in the reading settings.

The search box above the tree (Ctrl+Shift+F) finds text in every Markdown file of the folder — matches show the file and a snippet, and opening one highlights the term in the document. Esc clears the search and brings the tree back.

Outline

The right panel lists the document headings and highlights the one you are reading. Click any entry to jump to it. On long documents a filter box appears above the list: type to narrow the headings, then ↑ / ↓ and Enter jump to one; Esc clears it.

Live reload

The open file is watched on disk. When it changes, the view refreshes automatically and keeps your reading position — useful while a document is being regenerated. In edit mode the refresh only happens while your buffer has no unsaved changes.

F5 or Ctrl+R reads the file again on request, keeping your place; with unsaved edits it does nothing.

Rendering

  • GitHub-flavored Markdown: tables, task lists, strikethrough, autolinks.
  • Code blocks are syntax-highlighted and have a copy button on hover.
  • mermaid code fences render as diagrams; invalid syntax falls back to the code block with an error note.
  • Click a diagram or an image to open it full-window: + / − or the scroll wheel zoom, dragging pans, 0 fits it to the window and Esc closes. The copy button offers the image as PNG (normal or large), a diagram also as SVG, and both can be saved to a file.
  • Math renders with KaTeX: $…$ inline, $$…$$ or a math code fence for display blocks.
  • GitHub-style callouts: a quote starting with [!NOTE], [!TIP], [!IMPORTANT], [!WARNING] or [!CAUTION].
  • Footnotes: [^1] in the text and [^1]: … anywhere; the notes are collected at the end, with links there and back.
  • Task lists are live: clicking a checkbox updates the [ ] / [x] in the file right away (with an Undo in the notice), or in the editor buffer while you are editing.
  • Tables have a copy button on hover that puts them on the clipboard as tab-separated text, ready for Excel or Google Sheets.
  • Links to other documents work like a wiki: [text](other) finds other.md, [text](folder/) opens the folder's index.md or README.md, and other.md#section jumps to that heading.
  • YAML front matter between --- lines is folded into a Front matter block at the top: click it to see the fields as a table.
  • A paragraph containing only [TOC] becomes a table of contents of the headings that follow, which also goes to print, HTML and DOCX.
  • Images with relative paths resolve against the document's folder.
  • Links to web pages open in your default browser, mailto: links in your mail app; links to other Markdown files open in the viewer, to images in the preview, to a folder in the file browser. A link to any other file (a PDF, a spreadsheet) offers to open it in its own app.
  • Simple HTML in the text works: <br>, <kbd>, <sup>, <details>, images (<picture> and srcset too), video and audio from the document's folder. As on GitHub, a tag that is not HTML, such as <name>, does not show: to show it, write it between backticks (`<name>`) or with a backslash in front (\<name>). Tags that would change the page, such as <style>, <script>, <title> and <iframe>, show as text.

Sharing and export

The Share button (Ctrl+Shift+E) collects everything that leaves the app:

  • Copy as rich text (Ctrl+Shift+C): puts the rendered document on the clipboard with formatting, ready to paste into Outlook, Word or Teams. Local images are embedded.
  • Print… (Ctrl+P): prints only the document, laid out for paper, always on a light background, with the title and date at the top of every page and "page / pages" at the bottom.
  • Save as PDF: the same layout written straight to a PDF file, no dialog other than the file picker. New page at every heading 1 is an option in the menu, remembered, for both.
  • Export as HTML / DOCX: saves the document as a single self-contained .html page that opens in any browser, or as a .docx optimized for Microsoft Word — math becomes native Word equations, diagrams become images.

Printing and exports always use the standard text layout, whatever reading settings are active.

Reading settings

The Aa button opens the reading settings: text size, sans or serif font, line spacing, column width and the theme: light, sepia (warm paper), dark, black (for OLED screens) or auto (light or dark following Windows). Text size is also available anywhere with Ctrl+= / Ctrl+−, Ctrl+scroll wheel, and Ctrl+0 to reset; the editor text scales along with it. Panels sets the text size of the file browser and the outline on its own — Ctrl+scroll wheel over a panel changes that one instead. Every choice is remembered across restarts.

Windows integration

Files you open are added to Windows' Recent items and to the app's taskbar jump list. Double-clicking any .md file in File Explorer opens it here once the association is registered by the installer.

Right-click a file in the browser panel, or the file name in the toolbar, to show it in File Explorer, copy its path, or copy a Markdown link to it relative to the open document. The pin button (Ctrl+Shift+T) keeps the window on top of the others.

A portable build is available on GitHub as a zip: unpack it anywhere and run it, and it keeps its settings in a data folder next to the program instead of your profile.
