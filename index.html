Markdown Viewer

A read-only viewer for Markdown documents. It never modifies the files it opens.

Opening documents

  • Double-click any .md file in File Explorer.
  • Drag a file onto the window.
  • Press Ctrl+O or use the folder button in the toolbar.

Opening a second file while the app is running reuses the same window.

Keyboard shortcuts

Ctrl+OOpen a file
Ctrl+FFind in document
Enter / Shift+EnterNext / previous match
Ctrl+BToggle the file browser
Ctrl+IToggle the outline
F1Show this help
EscClose the find bar or this help

Browsing files

The left panel lists the Markdown files in the folder you opened, up to four levels of subfolders. Opening a file from the panel keeps the same root folder, so you never lose your place; use the up arrow next to Files to move the root to the parent folder. Opening a document from outside the current folder re-roots the panel there.

Folders without Markdown files are hidden, as are hidden and build folders such as node_modules.

Outline

The right panel lists the document headings and highlights the one you are reading. Click any entry to jump to it.

Live reload

The open file is watched on disk. When it changes, the view refreshes automatically and keeps your reading position — useful while a document is being regenerated.

Rendering

  • GitHub-flavored Markdown: tables, task lists, strikethrough, autolinks.
  • Code blocks are syntax-highlighted and have a copy button on hover.
  • mermaid code fences render as diagrams; invalid syntax falls back to the code block with an error note.
  • Images with relative paths resolve against the document's folder.
  • Links to web pages open in your default browser; links to other Markdown files open in the viewer.

Theme

The viewer follows the Windows light/dark setting. The sun/moon button overrides it and remembers your choice.
