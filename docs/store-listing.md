## Product name

Leggimi – Markdown Viewer & Editor

## Description (max 10 000 characters)

Leggimi is a Markdown viewer and editor for Windows, made for the documents you read every day: the briefs, plans and summaries that ChatGPT, Claude and Copilot write, the README and docs of a project, your own notes. Double-click a .md file and read it as a clean, readable page; when something needs fixing, the editor is one key away.

MARKDOWN AND AI

Markdown is the format AI assistants write in: plain text with headings, lists and tables. Ask for a .md file instead of a Word document or a PDF and you spend fewer tokens: the text the model writes is the file itself, with no extra steps to build a document, and when you hand it back, the model reads it as it is, with nothing to convert.

Leggimi does the rest. While an agent rewrites the file, the page updates by itself and you stay where you were. The table of contents an AI puts at the top actually leads to the right section. When the brief has to reach someone else, one click copies it ready for Word, Outlook or Teams, formatting and diagrams included, or saves it as a PDF with page numbers. It works with any assistant, because it reads the files they leave on your disk.

FOR DEVELOPERS

Leggimi shows README, CHANGELOG, the docs folder, AGENTS.md and CLAUDE.md with GitHub's conventions: callouts such as [!NOTE] and [!WARNING], task lists, footnotes, Mermaid diagrams, KaTeX math and logos made for light and dark themes. Headings get the same anchors as on GitHub, so a link to a section works here as it does there. Links between files work without the .md extension too, and a link to a folder opens its README. From a terminal, leggimi file.md --line 42 opens the file at that line, in the window you already have open. Search the whole folder with Ctrl+Shift+F, keep a project open in tabs, and drag one out to set it beside your editor.

FOR BRIEFS, REPORTS AND MEETINGS

The text sits in a centered column with the outline of its headings alongside, and every document reopens where you left it; recent files wait on the start page. A window fits half a screen next to Teams, and the pin keeps it on top during a meeting. Choose light, sepia, dark or true black, the text size, a serif or sans font, line spacing and column width, and read with the keyboard if you like (j/k, . and ,). Wide tables and diagrams get the room they need, and a click opens a diagram full-window to zoom in.

FROM MARKDOWN TO WORD, OUTLOOK AND PDF

- Copy as rich text (Ctrl+Shift+C): headings, tables, code, callouts and diagrams paste into Word, Outlook and Teams with their formatting, and in Word formulas become equations.
- Save as PDF in one click, with a header and page numbers, and a new page at every heading 1 if you want one.
- Export as DOCX, where formulas become Word equations you can edit, or as a single HTML page that opens in any browser.

TABS AND WINDOWS

Open several documents in one window and move between them with Ctrl+Tab. Drag a tab to reorder it, out of the window to give it a window of its own, or onto another Leggimi window to move it there. The title bar takes the colors of the theme and leaves more room for the text, and the maximize button opens the Windows 11 Snap layouts. A file opened from File Explorer arrives in a new tab of the window you used last.

EDITING, WHEN YOU NEED IT

Ctrl+E opens the editor next to a live preview. A format bar and a "/" menu insert tables, diagrams, formulas and callouts, and the file stays plain Markdown. You also get find & replace, spellcheck in the interface language, line commands and a recovery draft that gives your unsaved text back after a crash. Files are written only when you press Ctrl+S, and Leggimi asks before overwriting a file that changed on disk.

AT A GLANCE

- Free, with every feature included, and open source under the MIT License.
- About 6 MB to download, and a document opens in under a second.
- Diagrams and formulas are drawn by the app itself, so it also works offline.
- Interface in English, Italian, German, French, Spanish and Simplified Chinese.
- WCAG AA contrast in all four themes, and the keyboard focus is always visible.
- On GitHub you will find the source code, the classic installer and a portable version to carry on a USB stick.

## What's new in 2.0.0 (max 1 500 characters)

Leggimi 2.0 brings tabs. Open several documents in one window and move between them with Ctrl+Tab; Ctrl+T opens a new tab on the start page, Ctrl+W closes one and Ctrl+Shift+T brings it back. Ctrl+click or the middle button opens a link, a file or a search result in a tab behind the one you are reading (Shift+click opens a new window), and a file opened from File Explorer or the terminal arrives in a new tab of the window you used last.

Drag a tab to reorder it, out of the window to give it a window of its own, or onto another Leggimi window to move it there. Every tab has its own reading position, edits and Back/Forward history, and takes them along when it moves, unsaved text included.

The title bar is now drawn by Leggimi in the colors of the theme (light, sepia, dark or black): tabs, commands and window buttons share one slim bar, so the text gets more room, and the maximize button still opens the Windows 11 Snap layouts. The pin button keeps the window on top; its old shortcut, Ctrl+Shift+T, now reopens a closed tab, as in browsers.

And Leggimi has a new icon.

## Notes for certification (optional, private to Microsoft)

Leggimi is a local Markdown viewer/editor. It needs no account. To test: open the sample
document from the "Open file" button or drop any .md file on the window. The app makes no
network requests; the only outbound action is opening web links in the default browser.
